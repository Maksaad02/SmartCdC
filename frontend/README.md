# RecOuVTeK Frontend

A modern web application for debt recovery and management, built with React, TypeScript, and Vite. This frontend provides a user-friendly interface for managing clients, debts, payments, and reminders in the debt collection process.

## 🚀 Features

- **Authentication & Authorization**
  - Secure user login and registration
  - Role-based access control
  - Profile management

- **Client Management**
  - Create and manage client profiles
  - View client history and status
  - Detailed client information tracking

- **Debt Management**
  - Create and track debts
  - Monitor debt status and history
  - Detailed debt information and documentation

- **Payment Tracking**
  - Record and track payments
  - Payment history visualization
  - Payment schedule management

- **Reminder System**
  - Automated reminder creation
  - Reminder scheduling and tracking
  - Custom reminder templates

- **Modern UI/UX**
  - Responsive design for all devices
  - Dark/Light theme support
  - Interactive dashboards and charts
  - Shadcn UI components

## 🛠️ Tech Stack

- **React** - Frontend library
- **TypeScript** - Type safety and better developer experience
- **Vite** - Next generation frontend tooling
- **Tailwind CSS** - Utility-first CSS framework
- **Shadcn UI** - High-quality UI components
- **React Router** - Application routing
- **React Query** - Server state management
- **React Hook Form** - Form handling
- **Zod** - Schema validation
